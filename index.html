Merangkai ide menjadi website yang hidup

Saya Zafira Ismi Samahiya, mahasiswa yang sedang menekuni dunia web development. Semuanya bermula dari rasa penasaran. Setelah mencoba satu baris kode dan melihat hasilnya muncul di layar, saya sadar bahwa inilah hal yang ingin saya dalami dengan serius.

Saat ini saya sedang mempelajari HTML untuk membangun struktur, CSS untuk membentuk tampilan, dan JavaScript untuk menghidupkan interaksi. Bagi saya, coding bukan sekadar menghafal sintaks. Coding adalah cara berpikir: memecah masalah besar menjadi langkah kecil, lalu menyusunnya hingga bekerja dengan baik.

Sebagai mahasiswa yang melangkah ke dunia engineering, saya belajar bahwa teknologi yang baik harus tepat guna, rapi, dan nyaman dipakai. Karena itu saya juga mendalami UI/UX, supaya setiap halaman yang saya buat bukan hanya berfungsi, tetapi juga terasa indah dan mudah digunakan.

Saya belajar pelan-pelan tetapi konsisten. Harapan saya, kelak menjadi developer yang kuat secara teknis dan punya ciri khas di setiap karya. Semua ini masih proses, dan saya menikmati setiap langkahnya.
